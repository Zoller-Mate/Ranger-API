# Ranger API and Manager

The API for the Ranger project

### In order to start working you have to

```cmd
cp .\config.env.example .\config.env
```

- Fill out config.env with your entries

```cmd
run npm i
```

- Start your local database

```cmd
npm run db:generate
npm run db:migrate
```

### To start the application id dev mode run:

```cmd
npm run dev
```

### To compile the scss for the frontend to css use:

```cmd
npm run css:compile
```
